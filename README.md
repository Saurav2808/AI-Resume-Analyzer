# 📄 AI Resume Analyzer & Mock Interview Agent

An end-to-end AI career assistant built with **LangChain**, **Google Gemini**, and **Streamlit**. It automates ATS resume evaluation, skill profiling, role-targeted resume rewriting, and conducts dynamic mock interviews with automated scoring.

---

## 🚀 Features

- **ATS Resume Scoring:** Analyzes resumes for strengths, weaknesses, missing keywords, and overall ATS compatibility.
- **Skill Extraction:** Parses and categorizes skills along with confidence and proficiency signals.
- **AI Mock Interview:** Generates interview questions tailored to the resume and target role, evaluating answers in real time.
- **Resume Rewriter:** Tailors resume content to specific job descriptions and exports structured, formatted HTML resumes.

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit
- **LLM Orchestration:** LangChain, LangChain Google GenAI
- **Model:** Google Gemini
- **Document Parsing:** PyMuPDF (fitz)
- **Data Modeling:** Pydantic
